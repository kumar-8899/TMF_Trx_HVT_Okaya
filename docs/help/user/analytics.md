# Analytics

A dashboard over your run history. Filter by **range / model / operator**, then read:

![Analytics — test quality, failures and cycle-time insights](asset:analytics)

- **Quality** — First-Pass-Yield control chart, pass/fail split.
- **Failures** — Pareto of failing tests (with cumulative line), parameter Pareto, failures by model.
- **Cycle time** — distribution histogram and an I-MR view.

Use it to find the biggest failure contributors and yield trends.
