# DAQ

Live data-acquisition view.

- **Stream cards** — analog (AI) and digital (DI) channels with live tiles + sparklines; channel and rate shown.
- **Variables panel** — read station variables; write digital outputs (set 0/1) where permitted.

Streaming comes from the LabVIEW controller over the bus. If nothing updates, check the station-readiness lamp and the controller link (Health).
